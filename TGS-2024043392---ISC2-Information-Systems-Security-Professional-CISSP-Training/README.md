Hands-on CISSP labs for learners preparing to think like security leaders and apply the eight CISSP domains in realistic scenarios. The labs cover security and risk management, asset security, security architecture and engineering, communication and network security, identity and access management, security assessment and testing, security operations, software development security, governance integration, and exam readiness.

## How to Use These Labs

1. Read the learner guide before starting the first lab.
2. Complete the labs in order because the later case studies reuse earlier risk, asset, IAM, and operations decisions.
3. Work from a manager-first security perspective: choose defensible, risk-aligned answers instead of only technical fixes.
4. Use the templates in each lab to produce evidence, decision logs, and exam-style reasoning notes.
5. Review the checkpoint questions after every lab.
