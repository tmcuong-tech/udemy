# Tools Guide

## Required Tools

| Tool | Purpose |
| --- | --- |
| Markdown editor or word processor | Lab notes, policy drafts, risk register entries. |
| Spreadsheet tool | Risk scoring, asset inventory, IAM matrix, audit tracker. |
| diagrams.net | Network, architecture, and data-flow diagrams. |
| Web browser | Access public security references and course materials. |

## Reference Resources

| Resource | Use |
| --- | --- |
| ISC2 CISSP references | Certification domain alignment. |
| NIST Cybersecurity Framework | Governance, risk, and control mapping. |
| NIST SP 800-53 / 800-61 / 800-34 | Security controls, incident response, contingency planning. |
| OWASP Top 10 | Web application security risks. |
| MITRE ATT&CK | Threat behavior and detection mapping. |
| CIS Controls | Practical safeguard mapping. |

## Recommended Templates

Create these files during the course:

```text
risk-register.md
asset-inventory.csv
iam-access-matrix.csv
incident-response-checklist.md
bcp-dr-summary.md
secure-sdlc-checklist.md
exam-mistakes-log.md
```

## Lab Evidence Standard

For every lab, capture:

- Scenario assumptions.
- Risk decision.
- Control selection.
- Business justification.
- Exam takeaway.
