# Lab 10 - Design Data, AI, Microsoft 365, and Exam Readiness Architecture

## Objective

Complete a capstone architecture covering Microsoft 365, data security, AI security, and SC-100 exam readiness.

## Scenario

Contoso wants to adopt Microsoft Copilot and expand analytics workloads. Security leaders need assurance that sensitive data, AI interactions, collaboration systems, and cloud data stores are protected.

## Prerequisites

- Review Microsoft Purview data security capabilities.
- Review Microsoft 365 security posture concepts.
- Review Defender for Office 365 and Defender for Cloud Apps.
- Review Azure data security services.

## Tasks

### Step 1 - Design Microsoft 365 security posture

Create a Microsoft 365 security plan:

| Workload | Security concern | Microsoft capability | Metric |
|----------|------------------|----------------------|--------|

Include:

- Exchange Online
- SharePoint Online
- OneDrive
- Teams
- Microsoft Defender for Office 365
- Defender for Cloud Apps
- Microsoft Secure Score

### Step 2 - Design data discovery and classification

Define:

- Sensitive information types
- Trainable classifiers, where appropriate
- Sensitivity labels
- Retention labels
- Data loss prevention policies
- Insider risk signals
- Audit requirements

### Step 3 - Design Azure data protection

Specify security for:

- Azure SQL
- Azure Storage
- Azure Cosmos DB
- Azure Synapse Analytics
- Key Vault
- Defender for Storage
- Defender for Databases

For each, include encryption, access control, network control, monitoring, and backup considerations.

### Step 4 - Design AI security controls

Write requirements for secure AI adoption:

- Data classification before AI rollout
- Least-privilege access to source data
- Prompt and response governance
- Plugin or connector review
- Logging and audit
- Sensitive data leakage controls
- Human oversight for high-risk decisions

### Step 5 - Build the capstone architecture

Combine your work from Labs 1 to 10 into one architecture package:

1. Executive summary
2. Top risks and priorities
3. Zero Trust strategy
4. Identity and privileged access model
5. Security operations model
6. Compliance and data protection model
7. Infrastructure and endpoint posture model
8. Application and DevSecOps model
9. Data, AI, and Microsoft 365 security model
10. 30/60/90-day roadmap

### Step 6 - Exam readiness review

Create a study tracker:

| SC-100 skill area | Confidence 1-5 | Evidence from labs | Next study action |
|-------------------|----------------|--------------------|-------------------|

Use the four current SC-100 skill areas:

- Design solutions that align with security best practices and priorities
- Design security operations, identity, and compliance capabilities
- Design security solutions for infrastructure
- Design security solutions for applications and data

## Deliverable

Submit:

- Microsoft 365 security plan
- Data discovery and classification design
- Azure data protection design
- AI security requirements
- Capstone architecture package
- Exam readiness tracker

## Checkpoint questions

1. Why should data classification happen before broad AI rollout?
2. How do Microsoft 365 controls connect to Zero Trust?
3. Which SC-100 domain needs your most review after completing the capstone?
