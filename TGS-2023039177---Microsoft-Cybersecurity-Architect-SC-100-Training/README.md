These are the hands-on lab exercises for the WSQ Microsoft Cybersecurity Architect (SC-100) Training course delivered by [Tertiary Infotech Academy Pte Ltd](https://www.tertiarycourses.com.sg/).

This repository contains **10 guided architecture labs** aligned to the Microsoft SC-100 exam skills measured. The labs emphasize security architecture decisions, Zero Trust design, Microsoft security capabilities, governance, threat modeling, and executive-ready design justification.

## How to use

1. Read the learner guide first to understand the case study, roles, and deliverables.
2. Open each lab and complete the steps in order.
3. Use the Microsoft Learn study guide as the exam blueprint while completing the architecture decisions.
4. Save your design outputs as Markdown, diagrams, tables, or screenshots as instructed.
5. Review the checkpoint questions at the end of each lab before moving on.
