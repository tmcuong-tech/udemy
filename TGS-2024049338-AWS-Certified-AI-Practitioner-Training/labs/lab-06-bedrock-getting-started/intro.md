# Lab 06 — Amazon Bedrock Getting Started

Enable foundation model access in Amazon Bedrock, explore the model catalogue, and run your first prompt in the playground.

**What you will do:**
- Open the Amazon Bedrock console and choose a Region where the service is offered
- Request access to at least two foundation models from two different providers
- Explore the model catalogue and record each model's provider, modality and use cases
- Run your first prompt in the Bedrock playground without writing any code
- List the same catalogue from the AWS CLI and inspect a single model's details
