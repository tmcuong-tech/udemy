# Lab 05 — The ML Pipeline and Data Preparation

Design a complete ML pipeline for a churn scenario, from business framing through data preparation and feature engineering to deployment and monitoring, grounded in the SageMaker console.

**What you will do:**
- Frame a business problem as an ML question and map the ten stages of the ML pipeline
- Plan data collection and exploratory data analysis, and identify target leakage
- Apply the pre-processing checklist and choose a defensible train/validation/test split
- Engineer features for the scenario and design a SageMaker Feature Store feature group
- Explain overfitting, hyperparameter tuning and the right evaluation metric for an imbalanced problem
- Choose a deployment option and design drift monitoring with SageMaker Model Monitor
