# Lab 12 — Prompt Engineering Basics — Zero-Shot and Few-Shot

Run one identical classification task at zero-shot, one-shot and few-shot in the Amazon Bedrock playground, and record exactly how and why the output quality changes.

**What you will do:**
- Fix one model, one temperature and one task so that only the prompt varies
- Identify the four parts of a prompt — instructions, context, input data and output indicator
- Run the task zero-shot and record where an underspecified prompt fails
- Add one example, then several, and measure what in-context learning actually buys you
- Compare all four prompting styles and find the point of diminishing returns
