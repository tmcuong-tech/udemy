# Lab 10 — Choosing Bedrock, SageMaker JumpStart or a Managed Service

Compare the three layers of AWS AI capability on the same task, build a decision table, and classify ten business scenarios against it.

**What you will do:**
- Learn the single question that separates managed AI services, Bedrock and SageMaker
- Run text through Amazon Comprehend and see what a task-specific managed API returns
- Run the same text through a Bedrock foundation model, then a task only Bedrock can do
- Browse the SageMaker JumpStart catalogue and see what a deployment would ask you to own
- Build a decision table across cost model, idle billing, output shape and control
- Classify ten business scenarios to the correct layer and justify each choice
