# Lab 07 — Comparing Foundation Models and Inference Parameters

Run one identical prompt across two or more foundation models, then hold the model constant and vary temperature, top-P and max tokens.

**What you will do:**
- Run an identical prompt on one foundation model and record how it answers
- Repeat the same prompt, unchanged, on a model from a different provider and compare
- Establish a low-temperature baseline and observe how repeatable the answers are
- Raise temperature and narrow top-P, and describe the difference between the two controls
- Set a small max tokens value and see the response truncated mid-sentence
