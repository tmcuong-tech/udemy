# Lab 02 — Data Types and Labelling for ML

Classify structured, semi-structured and unstructured data, store samples in Amazon S3, and produce a labelled image dataset with SageMaker Ground Truth.

**What you will do:**
- Classify datasets as structured, semi-structured or unstructured, and as tabular, time-series, image or text
- Create an Amazon S3 bucket and organise sample datasets by prefix
- Distinguish labelled from unlabelled data and plan a labelling task
- Create a SageMaker Ground Truth image classification job with a private work team
- Label the images yourself and read the resulting augmented manifest
