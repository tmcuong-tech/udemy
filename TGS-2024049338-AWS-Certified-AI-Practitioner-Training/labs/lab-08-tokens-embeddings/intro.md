# Lab 08 — Tokens, Embeddings and Vector Representations

Explore how text becomes tokens and why token counts drive cost and context limits, then generate embeddings with a Bedrock embedding model and measure semantic similarity.

**What you will do:**
- Predict and then check how different kinds of text split into tokens
- Work through the arithmetic of how token counts drive cost and fill the context window
- Generate an embedding vector from a Bedrock embedding model and inspect its dimensionality
- Compute cosine similarity between sentences and see meaning beat keyword overlap
- Trace how embeddings and a vector store form the retrieval half of a RAG system
