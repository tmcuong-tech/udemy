# Lab 02: Evidence Collection, Sampling, CAATs, Reporting, and Follow-Up

## Domain

Information Systems Auditing Process

## Objective

Build an evidence plan, select samples, design CAAT-style procedures, write findings, and define follow-up actions.

## Scenario

The audit from Lab 01 is underway. You must request evidence, test access and change controls, document exceptions, and prepare management-ready findings.

## Tasks

1. Create an evidence request list.
2. Classify evidence as inquiry, observation, inspection, or reperformance.
3. Define evidence quality criteria.
4. Select a sample of users, changes, incidents, or transactions.
5. Design a simple CAAT-style test using spreadsheet filters or formulas.
6. Record exceptions in a findings tracker.
7. Write a finding with condition, criteria, cause, effect, and recommendation.
8. Assign risk rating, owner, and target date.
9. Define follow-up procedures.

## Deliverables

- Evidence request list
- Sampling worksheet
- CAAT test notes
- Findings tracker
- Follow-up plan

## Review Questions

1. What makes evidence sufficient and appropriate?
2. When is sampling acceptable?
3. How do CAATs improve audit coverage?
4. What should be included in a complete finding?

## Cleanup

Retain evidence references and findings for the final readiness lab.
