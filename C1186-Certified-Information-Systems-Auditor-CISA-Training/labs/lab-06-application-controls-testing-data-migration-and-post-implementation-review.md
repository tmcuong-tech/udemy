# Lab 06: Application Controls, Testing, Data Migration, and Post-Implementation Review

## Domain

Information Systems Acquisition, Development, and Implementation

## Objective

Evaluate application controls, testing evidence, data migration controls, conversion results, and post-implementation review.

## Scenario

The customer portal has gone live. Audit must determine whether the system processes data accurately, migration was controlled, and post-implementation issues are tracked.

## Tasks

1. Identify key input controls.
2. Identify key processing controls.
3. Identify key output controls.
4. Review unit, integration, UAT, regression, and security test evidence.
5. Review data migration reconciliation.
6. Review conversion and rollback plans.
7. Assess defect and issue management after go-live.
8. Perform a post-implementation review checklist.
9. Draft a conclusion about system implementation control effectiveness.

## Deliverables

- Application controls matrix
- Testing evidence review
- Migration reconciliation checklist
- Post-implementation review notes
- Control effectiveness conclusion

## Review Questions

1. How do input, processing, and output controls differ?
2. What testing evidence is most useful to an auditor?
3. Why is data reconciliation important during migration?
4. What should a post-implementation review cover?

## Cleanup

Save control matrices and review notes.
