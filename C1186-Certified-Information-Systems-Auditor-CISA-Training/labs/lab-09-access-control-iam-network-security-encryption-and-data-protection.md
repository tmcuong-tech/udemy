# Lab 09: Access Control, IAM, Network Security, Encryption, and Data Protection

## Domain

Protection of Information Assets

## Objective

Audit controls that protect information assets through access management, network security, encryption, data handling, and privacy.

## Scenario

Sensitive customer and employee data is stored across applications, databases, file shares, and cloud services. Audit must assess whether access and protection controls are appropriate.

## Tasks

1. Review data classification and handling requirements.
2. Review access control models such as RBAC and ABAC.
3. Test a sample of user access for least privilege.
4. Review privileged access management evidence.
5. Review MFA and authentication controls.
6. Review network segmentation, firewall, IDS/IPS, or zero trust design evidence.
7. Review encryption, PKI, key management, and digital signature controls.
8. Review privacy and data retention requirements.
9. Draft an information asset protection finding.

## Deliverables

- Access review worksheet
- Privileged access test notes
- Network security control review
- Encryption and key management checklist
- Data protection finding draft

## Review Questions

1. What evidence supports least privilege?
2. How should privileged access be controlled?
3. Why is data classification important?
4. What risks arise from weak key management?

## Cleanup

Save the access and protection control worksheets.
