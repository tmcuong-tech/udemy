# Lab Tools and Templates

## Required Tools

- Spreadsheet editor
- Document editor
- PDF reader
- Browser
- Notes application

## Recommended Audit Templates

- Risk register
- Audit charter
- Audit program
- Evidence request list
- Evidence matrix
- Sampling worksheet
- Control test worksheet
- Findings tracker
- Follow-up tracker
- BCP/DR review checklist
- Access review checklist

## Optional Systems for Demonstration

- GRC platform
- Ticketing system
- IAM or identity administration portal
- Cloud console
- SIEM or log management dashboard
- Vulnerability scanner report
- Backup or disaster recovery dashboard

## Evidence Quality Checklist

Use this checklist for every evidence item:

- Is it relevant to the audit objective?
- Is it complete for the period under review?
- Is it reliable and from an appropriate source?
- Is it timely?
- Does it support the conclusion?
- Is it retained in a clear evidence index?
